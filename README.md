# Space Voice

Диктовка в любое текстовое поле macOS тем же жестом, что в bb (плагин Space Voice):
**тапните пробел, затем зажмите пробел** — говорите, — **отпустите** — текст вставится туда, где курсор.

- Быстрый двойной тап по-прежнему печатает два пробела.
- `Esc`, пока держите пробел, — отменить запись.
- Пробел первого тапа удаляется, если перед ним нет слова (как в плагине), и остаётся разделителем, если есть.
- Текст вставляется через буфер обмена, прежнее содержимое буфера возвращается.

Живёт в строке меню (иконка микрофона). Там же: вкл/выкл, «Выключить в «приложение»», выбор
распознавания, звуки, запуск при входе.

## Распознавание

| Движок | Что нужно | Качество |
| --- | --- | --- |
| **BB** (по умолчанию, если есть `bb`) | установленный bb | `bb voice transcribe` — тот же сервис, что выбран в bb (Codex / bb cloud): пунктуация, английские термины |
| **OpenAI** | свой API-ключ (меню → Распознавание → Ключ OpenAI) | `gpt-4o-transcribe` |
| **Apple, на устройстве** | macOS 26 | офлайн, слова видны по ходу речи; русский без пунктуации |

Если движок не выбран явно, берётся первый доступный в этом порядке.

## Права

При первом запуске macOS попросит:
1. **Универсальный доступ** (Accessibility) — чтобы слышать пробел во всех приложениях и вставлять текст.
2. **Микрофон**.

Права привязаны к подписи приложения, поэтому сборка всегда подписывается одним сертификатом.

## Сборка

```bash
scripts/build-app.sh                  # build/SpaceVoice.app, universal, подпись Apple Development
cp -R build/SpaceVoice.app /Applications/
```

Отладка движков без микрофона:

```bash
swift build && .build/debug/SpaceVoice --transcribe speech.wav --engine bb   # bb | openAI | apple
```

## Поделиться через Homebrew

Исходники приватные; наружу уходит только собранное приложение — zip в релизе публичного
[`grishaster80/homebrew-tap`](https://github.com/grishaster80/homebrew-tap) и cask там же:

```bash
scripts/release.sh 0.1.0
```

После этого любой ставит так:

```bash
brew install --cask grishaster80/tap/space-voice
```

Приложение не нотаризовано (нужен платный Developer ID), поэтому cask снимает карантин сам.
