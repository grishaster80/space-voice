# Space Voice

**Голосовой ввод в любом текстовом поле на Mac. Пробел → зажать пробел → говорить.**

[English](README.md) · [Лицензия MIT](LICENSE)

Space Voice — небольшое приложение в строке меню macOS. Поставьте курсор в чат, браузер,
редактор или терминал. Нажмите пробел, затем нажмите его ещё раз и держите, пока говорите.
Отпустите — распознанный текст вставится на место курсора.

Можно использовать свою подписку **Claude** или **ChatGPT через Codex**, сервис распознавания
из **bb**, свой **OpenAI API key** или локальную модель **Apple**.

![Окно Space Voice с выбором движка распознавания](docs/screenshots/window.png)

## Как пользоваться

1. Поставьте курсор в текстовое поле.
2. Нажмите пробел, затем зажмите пробел и говорите.
3. Отпустите — текст появится в поле.

Два быстрых нажатия остаются двумя пробелами. `Esc` отменяет запись.
Приложение вставляет текст через буфер обмена и восстанавливает его прежнее содержимое.
Для отдельных приложений жест можно отключить. В bb он по умолчанию отключён,
потому что там есть собственный плагин Space Voice.

![Плашка распознавания во время диктовки](docs/screenshots/dictating.png)

## Чем распознавать

| Движок | Что нужно |
| --- | --- |
| Claude | Подписка и вход в Claude Code. Показывает слова во время речи; язык выбирается в приложении. macOS запросит разрешение прочитать данные входа в Keychain. |
| Codex / ChatGPT | Подписка ChatGPT и вход в Codex CLI с локальным `auth.json`. Язык определяется автоматически. |
| bb | Установленный CLI bb. Используется выбранный в bb голосовой сервис. |
| OpenAI API | Свой API key, оплата за использование. Ключ хранится в Keychain. |
| Apple on-device | macOS 26 и модель нужного языка. После загрузки модели работает офлайн. Русский текст — без пунктуации. |

Интеграции Claude и Codex используют внутренние сервисы соответствующих продуктов.
Это не официальные публичные API: доступность зависит от аккаунта, лимитов и изменений у провайдера.
Отдельный API key для этих двух движков не нужен. При истечении входа нужно снова открыть соответствующий CLI.

На macOS 26 при ошибке облачного распознавания после запуска сессии приложение пробует
распознать ту же запись локально через Apple. Для этого нужны поддерживаемый язык и его модель.

## Установка

Нужна **macOS 14+**, для движка Apple — **macOS 26**.
Первый открытый выпуск доступен в исходниках; готового скачивания и Homebrew cask пока нет.
Для сборки нужен **Xcode 26+** с macOS 26 SDK.

```bash
git clone https://github.com/grishaster80/space-voice.git
cd space-voice
scripts/build-app.sh
cp -R build/SpaceVoice.app /Applications/
open /Applications/SpaceVoice.app
```

Скрипт собирает приложение для Apple silicon и Intel и подписывает первым найденным
сертификатом Apple Development либо ad hoc. Приложение пока не нотарифицировано.
При первом запуске разрешите доступ к микрофону и Accessibility.
Повторные сборки лучше подписывать тем же сертификатом, чтобы macOS сохраняла разрешения.

## Приватность

Микрофон включается, когда вы зажимаете пробел. Облачные движки отправляют запись своему
провайдеру; bb передаёт её настроенному в нём сервису. Apple распознаёт на устройстве
после загрузки языковой модели. У приложения нет собственной аналитики и сервера.

Встроенных ключей нет. Данные входа читаются локально, отдельная копия не сохраняется.
Если распознать запись совсем не удалось, последняя такая запись остаётся в
`~/Library/Caches/io.github.grishaster80.spacevoice/last-failed.wav` для повторной попытки.
Следующая ошибка перезапишет её.

Подробности разработки и выпуска — в [английском README](README.md).
Баги и предложения можно присылать в Issues, изменения — в pull requests.
Не прикладывайте токены, файлы входа и личные записи; об уязвимостях сообщайте [приватно](SECURITY.md).
